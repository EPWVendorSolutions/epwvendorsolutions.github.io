# Vendor Management Solutions website

A five-page static website for Effie Patricia Williams & Company LLC. Open `index.html` to review it locally. No build tools or paid hosting are required.

## Publish with GitHub Pages

1. Create a GitHub repository and upload the contents of this folder to its root.
2. In the repository, open **Settings → Pages**. Under **Build and deployment**, choose **Deploy from a branch**, select `main` and `/ (root)`, then save.
3. Review the temporary `github.io` address before connecting `EPWVendorSolutions.com`.
4. For a custom domain, follow GitHub's current Pages instructions and configure DNS with your domain registrar. Verify the domain in GitHub and enable HTTPS after DNS is active.

## Before launch

- Confirm that `info@epwvendorsolutions.com` is active and receiving mail. The contact page uses a `mailto:` link, which opens a visitor's email app; it is not a hosted inquiry form.
- Review all service copy and the logo, especially the official EPW mark. The supplied VMS graphic is used on the home page; the header uses styled text because the available EPW & Company image has a visible checkerboard background.
- Replace or add genuine photographs and product images when approved. No sample images or unverified testimonials are shown.
- Test all pages on a phone and desktop before publishing.
